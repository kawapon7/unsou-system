# 取引先一括インポート 運用マニュアル（運営者用）

対象: **運営者（ボス）のみ**。この機能は `OPERATOR_USER_IDS` に登録されたアカウントだけが使えます（他の管理者にはメニューに表示されず、URL直打ちでも404）。

用途: 新規導入先（クライアント企業）の請求先・部署・委託先マスタを、Excelから一括登録する。導入初期の1回きりの作業を想定。

> クライアントに渡す記入ルールは、Driveフォルダ内の「【はじめにお読みください】取引先一覧の記入ガイド」に集約してある。このマニュアルは運営側の手順だけを書く。

---

## 0. 前提条件

- 本番の Cloudflare Workers secret `OPERATOR_USER_IDS` に自分のユーザーUUIDが設定済みであること（2026-08-24 設定済み）
- 対象テナントの管理者としてログインできること

## 1. クライアントとのファイル受け渡し（Google Drive）

セキュリティ方針: **口座情報を含むためメール添付は使わない。** Google Drive の限定共有のみ。

1. Drive にクライアント専用フォルダを作る（例:「HIBIKI_取引先インポート（A社）」）
2. フォルダに入れるもの:
   - 最新テンプレ「HIBIKI_取引先インポート.xlsx」（インポート画面の「テンプレートをダウンロード」で取得したもの）
   - 記入ガイドのドキュメント
3. フォルダを**相手のメールアドレス指定**で共有する（「リンクを知っている全員」にはしない）
4. 記入完了の連絡を受けたら、フォルダから記入済みファイルをダウンロード

## 2. インポート手順

1. 本番にログイン → サイドバー「マスタ・設定」→「**取引先インポート**」
2. 記入済みファイルを選択 → 件数（請求先◯件／部署◯件／委託先◯件）を確認
3. 「この内容で一括登録する」を押す

### エラーが出たら

- **1件でもエラーがあると全件中止**される（中途半端に登録されることはない）
- エラー表にシート名・行番号・列名・理由が出る。行番号はExcelの行番号そのまま
- Excelを直してから、同じ手順でやり直せばよい（成功するまで何度でも安全）

### 「既に登録されている◯◯です」が出たら

- 同名の請求先・委託先が既にDBにある。過去に手入力した分と重複していないか取引先マスタを確認し、ファイル側から該当行を消してやり直す

## 3. 投入後にやること（順番厳守）

1. **取引先マスタで内容を目視確認**（件数・名前・口座の登録有無）
2. 代表者が現場稼働するクライアントの場合:
   1. 取引先マスタで代表者本人を委託先登録（「自社（代表者・従業員）」チェックON）
   2. アカウント管理 →「＋ドライバー追加」で、代表者の**別メール**の子分アカウントを発行して紐づけ
3. Driveフォルダの記入済みファイルは、登録完了後に**削除**する（口座情報入りのファイルを残さない）。ローカルのダウンロードフォルダからも削除

## 4. 補足（仕様の要点）

- 口座番号はDBに **AES-256-GCM で暗号化**されて保存される（平文では残らない）
- テンプレの2行目（※必須/任意ガイド）と3行目（例）行）は、残したまま取り込んでも無視される
- アカウント管理画面で運営者アカウントは「システムサポート」表記になり、クライアントからメールアドレスは見えない・編集/削除もできない
