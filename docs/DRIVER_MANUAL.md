# hibiki ドライバー向け かんたん操作マニュアル

対象: 委託先ドライバーのみなさん
やることは3つだけ: **① 予定を見る → ② 仕事が終わったら完了報告 → ③ 月末に支払を承認**

> 困ったら: 画面名・何をしたか・出たメッセージ の3点をそのまま管理者に送ってください。

---

## 0. ログイン（最初の1回だけ設定）

**URL**

```
https://unsou-system.hibiki-app.workers.dev
```

- スマホのブラウザ（Safari / Chrome）でこのURLを開くだけ。アプリのインストールは不要
- **ホーム画面に追加** しておくとアプリのように起動できます
  - iPhone: Safari で開く → 共有ボタン → 「ホーム画面に追加」
  - Android: Chrome で開く → 右上メニュー → 「ホーム画面に追加」

**ログイン方法**

1. URLを開くとログイン画面が出ます
2. **管理者から伝えられたメールアドレスとパスワード** を入力
3. ログインすると自動で **マイページ** が開きます

> 一度ログインすれば、次回からはURLを開くだけで自分の画面に直行します。

**画面の見かた（下メニュー3つ）**

| メニュー | 何ができる |
|---|---|
| **ホーム** | 今月の支払見込み・未承認の支払通知書の件数・次の予定 |
| **予定・実績** | 自分の予定一覧。完了報告と立替金申請はここ |
| **支払** | 月末に届く支払通知書の確認・承認。過去の支払履歴もここ |

名前・メール・インボイス区分の確認は右上の **プロフィール** から。

---

## 1. 毎日やること

### ① 予定を見る

**予定・実績** を開くと自分の予定が並んでいます。今日の仕事と次の予定を確認してください。

### ② 仕事が終わったら「完了報告」

1. **予定・実績** で終わった予定を開く
2. **完了報告** で実績を入力する
3. 高速代・燃料代などの **立替金** があれば、同じフォームでそのまま申請する
   - 領収書はなくさず保管してください（後で確認を求められることがあります）
4. 送信して完了

> 立替金は管理者が承認したものだけが支払に乗ります。申請を忘れると支払われないので、**その日のうちに** 入力するのがおすすめです。

---

## 2. 月末にやること（支払の承認）

月末になると、管理者からその月の **支払通知書** が届きます。

1. **支払** を開く（ホームにも未承認の件数が出ます）
2. 支払通知書の明細を確認する
   - 仕事の件数・金額、承認された立替金、運送保険料の相殺（引かれる分）が載っています
3. 金額が合っていれば **承認** する
4. 金額がおかしいと思ったら、**承認せずに** 管理者へ連絡してください

> あなたの承認を待ってから支払が確定します。通知が来たら早めの確認をお願いします。
> 返事がないまま日数が過ぎると、管理者側で確定される場合があります。

---

## 3. よくあるつまずき

| 症状 | 対処 |
|---|---|
| ページが開かない | URLが `https://unsou-system.hibiki-app.workers.dev` か確認 |
| ログインできない | メール・パスワードを再確認（大文字小文字に注意）。それでもダメなら管理者に連絡 |
| 自分の案件（仕事）が画面に出ない | 管理者側の設定の可能性があります。管理者に「案件が見えない」と伝えてください |
| 立替金が支払通知書に載っていない | まだ管理者が承認していない可能性。申請済みかどうかと合わせて管理者に確認 |
| 承認した内容を直したい | 自分では変更できません。管理者に連絡してください |
