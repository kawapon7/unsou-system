# hibiki フィールドテスト かんたん操作マニュアル

対象: フィールドテストに参加する **親分（管理者）** と **子分（委託先ドライバー）**
前提: 本番DBは白紙の状態（管理者アカウント `admin@hibiki.com` のみ）から始めます。

> 困ったら: 画面名・何をしたか・出たメッセージ の3点をそのまま開発担当に送ってください。

---

## 0. アクセス先とログイン

**URL（親分・子分 共通）**

```
https://unsou-system.hibiki-app.workers.dev
```

- スマホでもPCでも、ブラウザ（Safari / Chrome）でこのURLを開くだけ。アプリのインストールは不要
- スマホは **ホーム画面に追加** しておくとアプリのように起動できます
  - iPhone: Safari で開く → 共有ボタン → 「ホーム画面に追加」
  - Android: Chrome で開く → 右上メニュー → 「ホーム画面に追加」

**ログイン**

1. 上のURLを開くとログイン画面が出ます
2. メールアドレスとパスワードを入力してログイン
   - 親分: `admin@hibiki.com` と設定済みパスワード
   - 子分: 親分から伝えられたメールアドレスとパスワード（§1-⑤で発行）
3. 役割に応じて自動で振り分けられます
   - 親分 → **ホーム画面**（`https://unsou-system.hibiki-app.workers.dev/admin`）
   - 子分 → **マイページ**（`https://unsou-system.hibiki-app.workers.dev/driver/home`）

> ログインしたままなら、次回からは上のURLを開くだけで自分の画面に直行します。

## 1. 最初にやること（親分・初日のセットアップ）

**この順番で登録してください。** 後の画面は前の登録を前提にしています。
画面はすべてサイドバー **「マスタ・設定」** の中にあります。

| 順 | 画面 | 登録するもの | メモ |
|---|---|---|---|
| ① | **自社情報** | 会社名・インボイス登録番号・住所・電話・メール・振込先口座 | **会社名と登録番号が空だと、請求書も支払通知書も作れません**（安全のためわざと止まる仕様）。ここには **運送保険料（月額・既定1,000円、子分の支払額から相殺）** と **支払通知書の返事待ち日数（既定7日）** の設定もあるので初日に確認 |
| ② | **取引先マスタ › 荷主** | 仕事をもらう会社 | 請求書の宛先。「部署で請求を分ける」にチェックすると部署ごとに請求書を分けられる |
| ③ | **取引先マスタ › 委託先** | 仕事を出すドライバー（個人事業主）。**メールアドレスは⑤で発行するログイン用メールと同じものを** | 支払通知書の宛先。口座情報は暗号化して保存されます |
| ④ | **案件管理** | 荷主ごとの仕事 | 2段階で設定: (1) 案件本体で **担当委託先** と **「ドライバーに表示」** をON → 子分の画面に出る条件。 (2) **支払先** パネルで誰にいくら払うか（精算方法は「件数×単価」か「月額固定」）→ 支払通知書の計算元 |
| ⑤ | **アカウント管理** | 子分のログインアカウント | 委託先を選んでメール＋パスワードを発行 → 子分に伝える。必要なら「担当案件の振り分け」で子分に見せる案件をさらに絞れる（未設定なら担当委託先の案件が全部見える） |

①〜⑤が終われば日常運用に入れます。

## 2. 日常の流れ

### 親分（サイドバー「日常業務」）

- **業績サマリー**: 今月の **売上・仕入・粗利**。「サマリー」「案件別」タブ。毎朝ここを見る
- **案件カレンダー**: 全ドライバーの稼働予定（予定／休み／実績済）を日・週・月で俯瞰。予定の登録・一括登録・前月コピーができる

### 子分（マイページ・下メニュー3つ）

- **ホーム**: 今月の支払見込み・未承認の支払通知書の件数・次の予定
- **予定・実績**: 自分の予定一覧。仕事が終わったら **完了報告**（実績の入力と、高速代・燃料などの **立替金申請** が同じフォーム）
- **支払**: 月末に親分から届く支払通知書を確認して **承認** する。過去の支払履歴もここ
- プロフィール（右上）: 名前・メール・インボイス区分の確認

## 3. 月末・月初の流れ（親分・サイドバー「月次・締め業務」）

```
① 立替金・勤務記録の承認 → ② 荷主への請求書 → ③ 子分への支払通知書 → ④ 子分が承認 → ⑤ 確定・ロック → ⑥ 収支確認
```

| 順 | 画面 | やること |
|---|---|---|
| ① | **承認管理** › 立替金承認 ／ 勤務記録承認 | 子分から上がった立替金を承認／却下、勤務記録を確認。承認した立替金だけが支払通知書に乗る |
| ② | **売上・請求管理（IN）** › 請求書生成 | 荷主ごとに当月の請求書プレビュー → 内容確認 → 確定（PDF） |
| ③ | **請求・支払管理(OUT)** | 委託先ごとに支払通知書を生成（「全員分を一括生成」も可）。運送保険料は自動で相殺される |
| ④ | （子分側）**支払** | 子分が金額を確認して承認 |
| ⑤ | **売上・請求管理（IN）** › 確定・ロック | 子分の承認が揃ったら **親分が確定**。**自動では締まりません。** 返事待ち日数（§1-①）を過ぎても返事がない場合は「未応答のまま確定」、電話等で合意済みなら「代理承認」ができる |
| ⑥ | **収支管理ビュアー** | 月次損益（総売上IN／総支払OUT／粗利）・荷主別粗利・推移グラフ・承認進捗 |

- **AIスキャン**: 紙の書類を写真で取り込む補助機能。「売上書類（荷主からの発注書・受領書）」と「支払書類（委託先からの請求書・領収書）」の2種類。うまく読めなければ手入力でOK
- **承認管理 › 承認履歴**: 誰が・いつ承認したかの記録。後から変更できません

## 4. よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| ページが開かない | URLが `https://unsou-system.hibiki-app.workers.dev` か確認（古い `kawapon7` 入りのURLは使わない） |
| 請求書・支払通知書を作ろうとするとエラー | 自社情報の **会社名・インボイス登録番号** が未入力。§1-① を埋める |
| 親分（自分）も現場に出る | 管理者アカウントではドライバー画面は使えません。取引先マスタ › 委託先 に自分を登録し、アカウント管理で**別のメールアドレス**（例: `xxx+driver@gmail.com`）の子分アカウントを発行して、スマホはそちらでログインしてください。⚠️ 自分担当の案件は当面、支払通知書を確定しないでください（自社分が外注費として載る修正が未対応） |
| 子分がログインできない | アカウント管理で発行したメール・パスワードを再確認。大文字小文字に注意 |
| 子分の画面に案件が出ない | 案件管理でその案件の **担当委託先** が本人になっているか、**「ドライバーに表示」** がONか確認。それでも出なければ、子分アカウントのメールと委託先マスタのメールが一致しているか確認 |
| 支払通知書に立替金が乗らない | 立替金がまだ **未承認**。承認管理 › 立替金承認 を先に |
| 支払通知書が確定しない | 自動では確定しません。売上・請求管理（IN）› 確定・ロック で親分が操作 |
| 確定した支払通知書を直したい | 確定ロック後は通常操作で変更不可。開発担当に連絡（開発者アンロック手順あり） |
